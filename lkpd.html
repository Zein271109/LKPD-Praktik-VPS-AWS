Fase 2

Persiapan dan Provisioning Server

4/4 Tahapan Selesai

Beri tanda centang pada kotak setelah Anda berhasil menyelesaikan setiap tahapan di konsol AWS:

PENTING: Manajemen Key Pair

Saat melakukan provisioning, AWS akan meminta Anda membuat Key Pair. File berakhiran .pem atau .ppk ini adalah "kunci rumah" server Anda. Simpan file ini di tempat yang aman. Jika hilang, Anda akan kehilangan akses ke dalam server.

Fase 3

Jaringan, Keamanan, dan Akses Server

Firewall & SSH

Isi tabel Security Group di bawah ini dengan port yang benar untuk mengizinkan akses ke server web Anda:

Tipe Akses Protokol Port Range Source (Sumber) Deskripsi / Kegunaan
SSH TCP Anywhere (0.0.0.0/0) Akses remote terminal
HTTP TCP Anywhere (0.0.0.0/0) Akses website tanpa enkripsi
HTTPS TCP Anywhere (0.0.0.0/0) Akses website aman (SSL)
Custom TCP TCP My IP Akses panel admin khusus

Fase 4

Konfigurasi Sistem Operasi & Web Server

Linux CLI & Apache/Nginx

Pasangkan perintah Linux berikut dengan fungsi yang tepat:

1 sudo apt update
Jawaban: C Memperbarui daftar paket repositori OS.
2 sudo systemctl restart apache2
Jawaban: D Memuat ulang layanan web server.
3 ls -la
Jawaban: A Menampilkan seluruh file termasuk yang tersembunyi.
4 chmod 400 key.pem
Jawaban: B Mengubah hak akses file menjadi read-only.

Tugas Praktik Web Server:

  1. Instal Apache atau Nginx pada server Anda.
  2. Buat file index.html kustom di direktori /var/www/html/.
  3. Buka IP Publik server Anda di browser.

Fase 6

Manajemen, Monitoring & Backup

CloudWatch & EBS Snapshot

Pemeliharaan server sangat penting. Gunakan AWS CloudWatch untuk melihat status server Anda dan dokumentasikan metrik saat ini.

Catat Metrik Server Saat Ini (CloudWatch):

Healthy
Rata-rata CPU Utilization:
Status Check Failed:

Langkah Backup (Snapshot):

  1. Buka menu Volumes di konsol EC2.
  2. Pilih Volume server Anda.
  3. Klik Actions > Create Snapshot.
  4. Beri deskripsi dan simpan.
